# Застосовані техніки та розшифровка коду

У проєкті реалізовано адаптивну верстку лендінгу LumiDecor з використанням сучасних можливостей CSS3, Flexbox, CSS Grid, медіазапитів та JavaScript.

## **Гнучка сітка (Flexbox & CSS Grid)**

**Flexbox:** використано для вирівнювання та розташування елементів в одному напрямку. Зокрема, Flexbox застосовується у шапці сайту, навігації, головному контенті, секції категорій, відгуках, формі підписки та футері.

`Furnishop.css` — блоки `.header`, `.nav ul`, `.hero__content`, `.store`, `.store__track`, `.reviews`, `.news__inner`, `.footer__top`.

Наприклад, у шапці:

```css
.header {
    display: flex;
    align-items: center;
    justify-content: space-between;
}
```

Це дозволяє розмістити логотип і навігацію в одному рядку та вирівняти їх по центру.

**CSS Grid:** використано для побудови двовимірних сіток. Основні приклади — блок статистики, секції «Наша філософія» та «Блок переваг», сітка товарів, картки освітлення й декору та колонки футера.

`Furnishop.css` — `.stats`, `.about`, `.best`, `.grid`, `.decor-light-grid`, `.footer__cols`.

Наприклад, сітка товарів:

```css
.grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 40px 20px;
}
```

На широкому екрані товари розташовуються у чотири колонки, а за допомогою медіазапитів їх кількість змінюється для менших екранів.

## **Адаптивні медіазапити (Responsive Design)**

Для адаптації сайту під різні розміри екрана використано медіазапити:

```css
@media (max-width: 1024px)
```

```css
@media (max-width: 768px)
```

```css
@media (max-width: 480px)
```

`Furnishop.css` — блоки адаптації для планшетів, телефонів та маленьких телефонів.

На ширині до **1024px** сітка товарів переходить із чотирьох колонок у три, а колонки футера — з п'яти у три.

На ширині до **768px**:

* відкривається мобільне бургер-меню;
* навігація переходить у вертикальний список;
* статистика переходить у дві колонки;
* секції `.about` та `.best` стають одноколонковими;
* товари відображаються у дві колонки;
* відгуки переходять у вертикальне розташування;
* форма підписки стає вертикальною;
* футер переходить у дві колонки.

На ширині до **480px** додатково зменшуються розміри кнопок та тексту, а також коригується позиціонування фонового зображення.

## **Сучасні функції CSS та відносні одиниці**

У проєкті використано функцію `clamp()` для адаптивного розміру шрифтів:

```css
--fs-title: clamp(28px, 1.2rem + 2.4vw, 48px);
--fs-heading: clamp(22px, 1.1rem + 1.1vw, 32px);
--fs-body: clamp(13px, 0.78rem + 0.15vw, 15px);
```

`clamp()` дозволяє встановити мінімальне, бажане та максимальне значення. Завдяки цьому розміри тексту плавно змінюються залежно від ширини екрана.

Також використано відносні одиниці:

* `rem` — для масштабування тексту відносно базового розміру шрифту;
* `%` — для розмірів відносно батьківського елемента;
* `vw` — для розмірів відносно ширини вікна браузера;
* `px` — для точних розмірів окремих елементів.

Наприклад:

```css
padding-top: clamp(56px, 10vw, 128px);
```

Завдяки цьому верхній відступ головного контенту адаптується до ширини екрана.

## **Інтерактивність та доступність**

Для інтерактивних елементів використано CSS-переходи `transition`, псевдокласи `:hover` та `:focus-visible`.

Наприклад:

```css
.btn {
    transition: background 0.2s;
}
```

А для клавіатурної навігації:

```css
:focus-visible {
    outline: 2px solid var(--c-primary);
    outline-offset: 2px;
}
```

У JavaScript реалізовано:

* відкриття та закриття мобільного меню;
* додавання товару за допомогою кнопки `+`;
* перемикання сторінок каталогу;
* перемикання відгуків клієнтів;
* перевірку email у формі підписки;
* фільтрацію карток освітлення та декору за категоріями.

# Пояснення щодо використаного шрифту

У проєкті використано шрифт **Saira**, який підключається безпосередньо через **Google Fonts**:

```html
<link href="https://fonts.googleapis.com/css2?family=Saira:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

Шрифт використовується як основний для текстового оформлення сайту:

```css
body {
    font-family: "Saira", system-ui, sans-serif;
}
```

**Причини використання:**

**Сучасний дизайн:** Saira має сучасний геометричний вигляд і добре підходить для інтерфейсу магазину освітлення та декору.

**Різні насиченості:** підключено накреслення від 300 до 700, що дозволяє використовувати різну товщину для заголовків, основного тексту та кнопок.

**Веб-оптимізація:** шрифт завантажується через Google Fonts і використовується без необхідності зберігати файли шрифту безпосередньо у проєкті.

# Контрольні питання

## 1. Чим відрізняються `display: flex` і `display: grid`, у яких випадках доцільний кожен?

**Flexbox** — одновимірна модель компонування. Вона працює переважно з елементами вздовж однієї осі — рядка або стовпця. У проєкті Flexbox використовується для шапки, навігації, кнопок, секції категорій, відгуків та інших компонентів.

**CSS Grid** — двовимірна модель компонування, яка працює одночасно з рядками та стовпцями. У проєкті Grid використовується для статистики, блоків із двома колонками, каталогу товарів, карток декору та футера.

---

## 2. Що роблять властивості `justify-content`, `align-items`, `align-content`?

`justify-content` — вирівнює елементи вздовж головної осі Flex-контейнера або відповідної осі Grid.

`align-items` — вирівнює елементи вздовж поперечної осі контейнера.

`align-content` — вирівнює рядки або стовпці Flex/Grid-контейнера, коли всередині нього залишається вільний простір.

У твоєму коді, наприклад:

```css
.header {
    display: flex;
    align-items: center;
    justify-content: space-between;
}
```

`align-items: center` вирівнює елементи по вертикалі, а `justify-content: space-between` розміщує їх по різних сторонах контейнера.

---

## 3. Як працює скорочення `flex: 1 1 0` і з чого воно складається?

`flex: 1 1 0` — це скорочений запис трьох властивостей:

`flex-grow: 1` — елемент може збільшуватися та займати вільний простір.

`flex-shrink: 1` — елемент може зменшуватися, якщо в контейнері недостатньо місця.

`flex-basis: 0` — початковий розмір елемента перед розподілом доступного простору дорівнює нулю.

У результаті вільний простір розподіляється між такими Flex-елементами відповідно до їх коефіцієнта `flex-grow`.

---

## 4. Призначення одиниці `fr` і функції `minmax()`

**`fr` (fraction)** — одиниця CSS Grid, яка визначає частку доступного простору контейнера.

У твоєму коді використовується:

```css
grid-template-columns: repeat(4, 1fr);
```

Це означає, що доступний простір розподіляється між чотирма колонками приблизно порівну.

Наприклад:

```css
grid-template-columns: 1fr 2fr;
```

створить дві колонки, де друга буде вдвічі ширшою за першу.

**`minmax()`** задає мінімальний і максимальний розмір Grid-елемента.

Наприклад:

```css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
```

дозволяє створювати адаптивну сітку, у якій колонка не стає меншою за `250px`, а вільний простір розподіляється між колонками.

---

## 5. Чим `grid-template-areas` зручніший за розстановку через `grid-column` і `grid-row`?

`grid-template-areas` дозволяє створювати структуру Grid за допомогою іменованих областей. Це робить структуру макета більш наочною.

Наприклад:

```css
grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
```

Після цього окремим елементам можна призначити відповідні області:

```css
header {
    grid-area: header;
}
```

Перевага полягає в тому, що структура сторінки читається безпосередньо з CSS.

**У моєму проєкті `grid-template-areas` не використовується**, оскільки розташування елементів реалізовано через `grid-template-columns`, `gap` та інші властивості Grid.

---

## 6. Що таке мобільний перший підхід і чим він відрізняється від десктопного?

**Mobile-First** — підхід, при якому спочатку створюється базова версія сайту для маленьких екранів, а потім за допомогою `@media (min-width: ...)` додаються стилі для більших екранів.

**Desktop-First** — спочатку створюється повна версія для великих екранів, після чого за допомогою `@media (max-width: ...)` вона адаптується для планшетів і телефонів.

У моєму проєкті використовується підхід, близький до **Desktop-First**, оскільки основні стилі спочатку описують повну версію для великих екранів, а потім через:

```css
@media (max-width: 1024px)
```

```css
@media (max-width: 768px)
```

```css
@media (max-width: 480px)
```

виконується адаптація до менших екранів.

---

## 7. Як обчислюється значення `clamp(min, preferred, max)`?

`clamp()` задає значення в межах трьох параметрів:

* **`min`** — мінімально допустиме значення;
* **`preferred`** — бажане значення, яке може змінюватися залежно від розміру екрана;
* **`max`** — максимально допустиме значення.

Наприклад:

```css
font-size: clamp(28px, 1.2rem + 2.4vw, 48px);
```

Розмір шрифту буде змінюватися залежно від ширини вікна, але не стане меншим за `28px` і не перевищить `48px`.

Це дозволяє створювати плавну адаптивну типографіку без необхідності задавати окремий розмір для кожної ширини екрана.

---

## 8. Різниця між одиницями `em`, `rem`, `vw`, `%`

**`rem` (root em)** — відносна одиниця, яка залежить від розміру шрифту кореневого елемента `<html>`.

**`em`** — відносна одиниця, яка залежить від розміру шрифту поточного або батьківського елемента.

**`vw` (viewport width)** — 1% ширини області перегляду браузера. Наприклад, `100vw` відповідає ширині вікна браузера.

**`%`** — відносна величина, яка залежить від відповідного розміру батьківського елемента.

У проєкті `vw` використовується разом із `clamp()` для адаптивних розмірів, а `rem` та `%` використовуються для створення більш гнучкого макета.

---

## 9. Навіщо потрібен метатег `viewport` і що станеться без нього?

У `<head>` документа використано:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Метатег `viewport` повідомляє мобільному браузеру, що ширина області перегляду повинна відповідати реальній ширині пристрою.

`width=device-width` встановлює ширину viewport відповідно до ширини пристрою.

`initial-scale=1` встановлює початковий масштаб сторінки рівним 100%.

Це особливо важливо для адаптивної верстки, оскільки без правильного viewport мобільний браузер може відображати сторінку так, ніби вона має значно ширший віртуальний екран, через що медіазапити можуть працювати не так, як очікується.
